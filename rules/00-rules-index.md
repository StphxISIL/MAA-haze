# Reglas de trabajo

Instrucciones para cualquier agente de IA que trabaje en este proyecto. Léelas antes de escribir o cambiar nada.

- [Cómo escribir aquí](01-how-to-write-here.md) | idioma, cabecera y formato de los documentos.
- [Qué nunca hacer](02-never-do.md) | los límites que no se cruzan.
- [Cómo versionar este proyecto](03-versioning.md) | el número `lp3.X.Y`, dónde se anota cada versión y el protocolo antes de cada commit.
- [Git](04-git.md) | la rama `main`, quién hace commit y push, las etiquetas y que ningún agente firma un commit.
